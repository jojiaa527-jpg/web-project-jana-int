Project Manager

Project Overview
Project Manager is a university web development project designed to help users organize and manage project information through a simple web interface.

Technologies Used
• HTML – Web page structure
• CSS – Styling and responsive design
• JavaScript – Form validation and dynamic content
• PHP – Project listing page

Features
• Homepage with a dynamic greeting and date/time display.
• Form for entering project names, descriptions, and statuses.
• Real-time project name validation.
• Project listing page with sample records.
• Simple navigation between pages.

Project Structure
• index.html – Homepage
• add_project.html – Project entry form
• projects.php – Project listing
• about.html – Project information
• validation.js – JavaScript functionality
• style.css – Application styling

My Contribution
I developed the application’s web pages and implemented the HTML, JavaScript, and PHP functionality, including form handling, validation, and project display. The CSS styling was completed by other team members.

Project Context
This project was developed as part of a university coursework assignment to apply web development concepts and practical programming skills.
